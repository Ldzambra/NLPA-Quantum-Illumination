Quantum Illumination using Nonlocal Non-Gaussian Photon Addition

This repository contains Python scripts supporting the manuscript “Quantum Illumination using Nonlocal Non-Gaussian Photon Addition”, by Luis D. Zambrano Palma, Yusef Maleki, and M. Suhail Zubairy.

The numerical calculations investigate quantum illumination using nonlocal non-Gaussian photon addition (NLPA), local non-Gaussian operations, two-mode squeezed states (TMSS), and classical illumination (CI).

Numerical validation

* Fig13.py: Convergence of the energy-normalized quantum Chernoff exponent with respect to Fock-space dimension.
* Fig14.py: Dependence of the energy-normalized quantum Chernoff exponent on signal brightness, thermal background, and target reflectivity.

Requirements

Python with NumPy, SciPy, and Matplotlib.
